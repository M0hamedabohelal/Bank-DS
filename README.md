# CS314 Data Science — بنك الأسئلة التفاعلي (100 سؤال)

تطبيق كويز تفاعلي متكامل ومريح للعين مبني باستخدام **React 19** و **Vite** و **Tailwind CSS**، يحتوي على **كافة الأسئلة الـ 100 كاملة دون نقصان** لمقرر علم البيانات (CS314) من الفصول 1 إلى 5، مع الشروحات الإنجليزية والأسباب (Why) والشروحات العربية الوافية.

---

## ✨ المميزات الرئيسية

1. **كويز تفاعلي بالرياكت:**
   - تقييم فوري مباشر لكل سؤال أو وضع الاختبار الشامل.
   - تنقل سريع بين الأسئلة عبر شبكة وفهرس الأسئلة الجانبي.
   - دعم اختصارات لوحة المفاتيح: الأزرار (`A`, `B`, `C`, `D`) لاختيار الإجابة، والأسهم (`←`, `→`) للتنقل السريع.
   - مؤثرات صوتية ناعمة ومريحة للسمع (عبر Web Audio API مباشرة دون الحاجة لملفات خارجية) قابلة للتشغيل/الكتم بضغطة زر.
   - احتفال تفاعلي بالكونفيتي (Confetti) عند إنهاء الاختبار وحساب النتيجة.

2. **بسيط جداً ومريح للعين:**
   - تصميم هادئ، حواف ناعمة، مساحات واسعة مريحة للقراءة والدراسة لساعات طويلة.
   - إمكانية تكبير وتصغير حجم الخط بـ 3 مستويات (`A`, `A+`, `A++`) لراحة تامة أثناء المذاكرة.

3. **خطوط جميلة وعصرية:**
   - خطوط عربية فائقة الوضوح: **Cairo** و **Tajawal**.
   - خط إنجليزي عصري: **Plus Jakarta Sans**.
   - خط مخصص للأكواد البرمجية: **JetBrains Mono**.

4. **4 ثيمات متناسقة (Themes):**
   - ☀️ **ناصع نهاري (Light)**: تباين عالي ناعم وخلفيات بيضاء نقية.
   - 🌙 **ليلي مريح (Dark)**: درجات الرمادي الداكن والـ Midnight لمنع إجهاد العين ليلاً.
   - 📜 **حماية العين (Warm Sepia)**: ثيم ورقي دافئ مصمم خصيصاً للدراسة وتقليل انبعاثات الضوء الأزرق.
   - 🌊 **أزرق هادئ (Nordic Navy)**: مزيج إسكندنافي هادئ من الأزرق البحري والتيل.

5. **هيكلة برمجية منظمة واحترافية:**
   ```
   src/
   ├── types/               # تعريفات TypeScript الكاملة (Question, Chapter, Theme...)
   ├── data/
   │   ├── chapters.ts      # بيانات الفصول الخمسة
   │   └── questions/       # تقسيم الأسئلة بشكل معياري ومنظم:
   │       ├── chapter1.ts  # الفصل 1 (20 سؤال)
   │       ├── chapter2.ts  # الفصل 2 (20 سؤال مع Context Note)
   │       ├── chapter3.ts  # الفصل 3 (20 سؤال)
   │       ├── chapter4.ts  # الفصل 4 (20 سؤال)
   │       ├── chapter5.ts  # الفصل 5 (20 سؤال)
   │       └── index.ts     # تجميع الـ 100 سؤال وتوفير دوال البحث والفلترة
   ├── context/
   │   ├── ThemeContext.tsx # إدارة الثيمات وحجم الخط وحفظها محلياً
   │   └── QuizContext.tsx  # إدارة حالة الكويز، الإجابات، المفضلة، والدرجات
   ├── components/
   │   ├── layout/          # Header, ChapterTabs, QuestionDrawer, Footer
   │   ├── quiz/            # QuestionCard, ExplanationCard, QuizControls, ResultsModal
   │   ├── study/           # StudyBrowseView (تصفح جميع الأسئلة والشروحات بدون كويز)
   │   └── common/          # ThemeSelector ومكونات مساعدة
   └── utils/
       └── sound.ts         # أصوات ناعمة وخفيفة مصنعة داخلياً
   ```

6. **تغطية شاملة لجميع الأسئلة الـ 100:**
   - **الفصل 1:** مقدمة في علم البيانات (20 سؤال: التعريفات، التخصصات، التاريخ، الـ Vs، أدوار العمل، وأنواع التحليلات).
   - **الفصل 2:** أدوات بايثون لعلم البيانات (20 سؤال: Jupyter Kernel, NumPy, Slicing, Broadcasting, Pandas, Loc/iloc, Groupby, List Comprehension, Git).
   - **الفصل 3:** أوجه البيانات وتصنيفاتها (20 سؤال: Structured/Unstructured/Semi, NLP Pipeline, Regex, Graph Data & Centrality, Density, Audio/Video, Streaming & Windows).
   - **الفصل 4:** منهجية ومراحل علم البيانات (20 سؤال: المراحل الست من Goal إلى Presentation و Automation، و CRISP-DM).
   - **الفصل 5:** حل المشكلات البرمجية باستخدام بايثون (20 سؤال: Computational Thinking, Loops, try/except, Functions Scope, Vectorization, Monte Carlo).

## 🚀 طريقة التشغيل

لتشغيل السيرفر المحلي في وضع التطوير:
```bash
npm run dev
```

لبناء المشروع للإنتاج (Production Build):
```bash
npm run build
```

لمعاينة نسخة الإنتاج:
```bash
npm run preview
```
